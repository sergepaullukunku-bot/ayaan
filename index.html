Règles et sauvegarde

Actif (MER) : date de référence ≤ date du prochain RDV + 28 jours ; décédés, transférés et patients sans date de début TARV exclus. Date probable : sans CV = début TARV + 6 mois ; CV faite dans les 12 premiers mois = début TARV + 12 mois ; ensuite dernière CV + 12 mois ; CV ≥ 1 000 copies = dernière CV + 3 mois. Une date antérieure au début de l'année fiscale compte comme attendue dès le premier mois (la date d'origine reste affichée) : le patient reste attendu chaque mois jusqu'au prélèvement. Patient raté : attendu le jour même jusqu'à minuit ; raté la veille, il est attendu aujourd'hui, et ainsi de suite. Réalisé : nouvelle CV dans Tier.Net pendant la période (la date effective se remplit alors seule, marquée « auto · Tier.Net ») ou date saisie par l'IT si l'export n'est pas à jour. Prochain RDV CV : dès qu'un prélèvement est fait (Tier.Net ou saisi), la date du prélèvement suivant est calculée selon les mêmes règles (ex. patient sous ARV depuis 2017 prélevé le 06/10/2026 : prochain RDV CV le 06/10/2027) ; elle est à communiquer au patient. En retard : date probable dépassée sans prélèvement ; le patient est signalé automatiquement pour le tracking actif. Vert ≥ 95 %, jaune 85 à 94 %, rouge < 85 %.

Les dates saisies sont gardées par N° dossier : elles ne se décalent pas quand vous importez un nouvel export. Toutes les données restent sur cet appareil, chiffrées (AES-256) : sans un code PIN valide, elles sont illisibles. Faites une sauvegarde régulière : le fichier de sauvegarde est lui aussi chiffré ; sur un autre appareil, il s'ouvre avec le code de secours de l'administrateur.
